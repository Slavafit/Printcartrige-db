# Отчёт по Task 018 — расширение совместимости

Дата: 13 октября 2026 года. Реализация: `cc1b857`. Объединена пользователем в `main` через PR #15, merge-коммит `9fe5868`.

## Что сделано

Через существующий импортёр обработаны реальные связи HP, Canon и Epson из PrinterTonerDB. Добавлены отчёты покрытия по базе и производителям, сравнение до/после, отдельное обозначение бутылочек с чернилами, сохранение цвета и исходных вариантов названий. Импорт стал атомарным: ошибка откатывает весь импорт, включая создание источника. Сторонний источник не может присвоить своим данным официальный статус.

Использована отдельная тестовая SQLite. Пользовательская рабочая база не изменялась. Поэтому приведённые цифры не означают, что установленное приложение автоматически получило новые данные.

## Ограничения и ошибки

**Нового массового источника относительно Task 016 не найдено.** Если импортировать тот же набор файлов старым импортёром Task 016, итоговое число покрытых принтеров и связей совпадает. Прирост относительно исходного seed составляет 2 755 покрытых принтеров; дополнительный прирост относительно уже выполненного импорта Task 016 — **ноль**.

Источник: [kurcz/PrinterTonerDB](https://github.com/kurcz/PrinterTonerDB/tree/ded2df49109534569dabe7b6a39df7713ac44bfc), опубликованный под Apache-2.0. Две локальные копии проверены по SHA-256; лицензия сохранена в репозитории. Исходный сайт, с которого автор собирал данные, не назван. Наличие записи в этом наборе не является официальным подтверждением производителя; неизвестный регион не подменяется европейским.

Отклонено 0 строк. Получено 10 609 предупреждений по полным исходным файлам, включая производителей вне выбранной тройки. Предупреждения касаются неизвестных типов/происхождения и неоднозначных либо нераспознанных идентификаторов; это не 10 609 отдельных ошибочных связей. [Диагностика с номерами строк](reports/task018/diagnostics.json).

Canon MAXIFY отсутствует в этом наборе; i-SENSYS представлен только тремя покрытыми моделями, Epson EcoTank — шестью. Это покрытие конкретного набора, а не доля всего рынка. Полный список непокрытых моделей находится в [after.json](reports/task018/after.json).

OpenPrinting не принят как источник массовых связей с расходниками: сведения о драйверах не подтверждают артикулы. Другой рассмотренный каталог содержит противоречивую лицензию с требованием письменного разрешения и не использован. Подробный разбор источников: [технический отчёт](task018-compatibility.md).

## Проверка сохранности

Все 55 официальных связей сохранены. Повторный импорт создаёт 0 новых принтеров, расходников, связей и источниковых утверждений. Проверка SQLite: `integrity_check = ok`, нарушений внешних ключей нет. Typecheck, build и все 114 тестов на момент завершения Task 018 прошли.

Для бутылочек добавлено поле `supply_form`, без перестроения таблиц. Перед миграцией существующей базы создаётся резервная копия. Строгий официальный импорт ink/toner не расширялся. Dry-run открывает существующую SQLite только для чтения.

## Как воспроизвести

Из корня проекта в PowerShell:

```powershell
pnpm.cmd task:018 --output-dir .collector-state/task018-report-check
```

Папка должна быть новой. Команда создаст отдельную `experiment.sqlite` и JSON-отчёты до/после, dry-run, импорта и повторного импорта. В рабочую базу приложение ничего автоматически не переносит. Команды явного импорта в выбранную копию базы находятся в [технической инструкции](task018-compatibility.md#reproduce-safely).

Следующее направление расширения — официальные подтверждения по непокрытым моделям, разбор нераспознанных идентификаторов и получение разрешённых каталогов поставщиков. Эти работы здесь не объявлены выполненными.
