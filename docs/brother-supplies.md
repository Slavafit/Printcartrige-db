# Brother: подготовка единого каталога расходников

Task 024 переводит завершённый Brother-аудит в общий multi-source формат. Генератор работает только с уже сохранёнными файлами `data/brother-compatibility.json` и `data/brother-audit.json`, не обращается к сайту и не изменяет SQLite.

## Результат

| Показатель | Значение |
|---|---:|
| Проверено связей во входном аудите | 1 611 |
| Принято точных cross-referenced связей | 1 606 |
| Принтеров | 292 |
| Уникальных расходников | 253 |
| Связей с картриджами ink/toner | 1 598 |
| Связей с бутылками ink_bottle | 8 |
| Исключено | 5 |

Исключены четыре строки со статусом `candidate` для `LC521BK` и одна строка `not-checkable` для `TN1050`. Они остаются в отчёте для ручной проверки и не получают `official_verified`. История исходного сбора также содержит шесть не загруженных страниц расходников; конвертер не пытается восполнить их догадками.

Четыре бутылки `BTD180BK`, `BTD180C`, `BTD180M` и `BTD180Y` сохраняются как `supply_form = ink_bottle`. Их восемь точных связей учитываются в общем числе проверенных связей расходников, но не в счётчиках OEM- или compatible-картриджей.

## Воспроизводимые команды

Сначала заново создать проверяемый пакет и отчёт:

```powershell
pnpm.cmd prepare:brother-supplies
```

Результаты находятся в `data/official/brother/brother-supplies.json` и `data/official/brother/brother-supplies-report.json`.

Безопасная проверка в памяти:

```powershell
pnpm.cmd db --db :memory: import:multi-source data/official/brother/brother-supplies.json --source-name "Brother España official pages" --source-category official --source-reference https://store.brother.es/ --region ES --dry-run
```

Ожидаемый результат: 1 606 валидных строк, 292 принтера, 253 расходника, 1 606 связей, ноль ошибок и ноль предупреждений. Повторный импорт проверяется автоматическим тестом и не создаёт дубликатов.

## Граница доверия

- Совместимость принимается только при статусе `cross-referenced` и точном совпадении сохранённых официальных URL принтера и расходника.
- Тип бутылки задаётся только для четырёх явно проверенных артикулов BTD180; для остальных строк сохраняется исходный тип `ink` или `toner`.
- Поле evidence хранит обе официальные страницы и дату аудита для каждой связи.
- Строгий legacy-импортёр OEM-картриджей по-прежнему принимает только ink/toner; расширенный пакет проходит через существующий multi-source pipeline.
- Рабочая/пользовательская SQLite не импортируется автоматически. Команда выше использует только базу в памяти.
